## 📐 PNG 尺寸说明

- **Logo 01, 02, 05, 06**（方形）: 256 / 512 / 1024 / 2048 px
- **Logo 03, 04**（横版字标）: 400 / 800 / 1600 px
- **Logo 07, 08, 09**（组合版）: 600 / 1200 / 2400 px
- **Logo 10**（图标）: 16 / 32 / 64 / 128 / 256 / 512 px

文件命名规则：`{编号}-{名称}@{宽度}.png`

例如：`01-quill-master-seal@1024.png` = 主印的 1024px PNG。

## 💡 使用建议

### 网站
- **Favicon**: 用 `10-quill-favicon-64@32.png` 或 SVG
- **网站 Header**: 用 `07-quill-lockup-horizontal.svg`
- **品牌墙图**: 用 `01-quill-master-seal.svg` 或 `02-quill-seal-clean.svg`

### 移动 App
- **App 图标**: 用 `10-quill-favicon-64@512.png`
- **启动屏 Splash**: 用 `02-quill-seal-clean@1024.png`

### 印刷材料
- **名片**: 用 `02-quill-seal-clean.svg` + `03-quill-wordmark-light.svg`
- **海报**: 用 `01-quill-master-seal.svg`（有纹理质感）+ `09-quill-vertical-stack.svg`
- **信封信纸**: 用 `02-quill-seal-clean.svg`（左上角）+ `07-quill-lockup-horizontal.svg`（页头）

### 社交媒体
- **头像（圆形）**: 用 `10-quill-favicon-64@512.png`
- **横幅 Banner**: 用 `04-quill-wordmark-dark@1600.png`
- **微信公众号**: 用 `06-quill-chop-chinese@512.png`（中文市场更受欢迎）

## ⚙️ 技术细节

### SVG 文件
- ✅ 所有文字已转为路径（outline），不依赖外部字体
- ✅ 可在 Figma / Illustrator / Inkscape 中直接编辑
- ✅ 可无限放大不失真
- ✅ 可任意改色（编辑 SVG 源码里的 HEX 值）

### PNG 文件
- ✅ 透明背景（除字标暗版外）
- ✅ 高清抗锯齿
- ✅ 适合即用，无需再加工
